第一次调用

服务地址为 https://radar.ydsdoa.cn/web-tool。从其他机器访问时，使用部署后的域名或 IP，并保留 /web-tool 前缀。
  • 在「API 密钥」页创建并保存完整密钥。下方示例中的密钥需要替换。
  • 调用 GET /v1/quota 验证密钥。这个请求不会访问搜索引擎。
  • 用 POST /v1/index/check 提交 URL。只查百度时，传入 "engines":["baidu"]。
1–20 条会在整批结束后返回 200。超过 20 条且任务队列开启时返回 202，可轮询任务并下载 CSV。

鉴权(X-API-Key / JWT)

公网 API(/v1/*)与 MCP 使用 API 密钥,在「API 密钥」页创建。管理 API(/api/*)使用管理员 JWT,由面板登录获得。
  • 推荐请求头:X-API-Key: sk-w2a-…
  • 兼容写法:Authorization: Bearer sk-w2a-…
密钥无效或已禁用时,返回 401 {"error":"unauthorized"}。当日配额用尽时,返回 429 {"error":"quota_exceeded"},响应携带 Retry-After,次日零点自动恢复。
cURL
curl "https://radar.ydsdoa.cn/web-tool/v1/quota" \
  -H "X-API-Key: sk-w2a-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

POST/v1/index/check

批量查询收录状态
提交 ≤20 条 URL 时，同一引擎按顺序逐条查，不同引擎可以并行。接口等整批结束后一次性返回 JSON。百度默认每分钟放行 5 次、突发额度为 1，20 条约需 4 分钟。
超过 20 条且已开启任务队列时，返回 202 和任务 ID。同步按成功单元扣费，未命中也计费。异步按提交的 URL 条数 × 引擎数扣费，重复 URL 也计入。提交前可自行去重。
参数类型必填说明
urlsarray[string]是待查询 URL 列表,1..index_jobs.max_urls(默认 5000);>20 条转异步任务
enginesarray[string]否省略时使用全部可用引擎。只查百度填 ["baidu"]。"360" 是 "so360" 的别名。
cURL
curl -X POST "https://radar.ydsdoa.cn/web-tool/v1/index/check" \
  -H "X-API-Key: sk-w2a-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://www.onlinedown.net/article/10049071.htm"
    ],
    "engines": ["baidu"]
  }'
JavaScript · fetch
const resp = await fetch("https://radar.ydsdoa.cn/web-tool/v1/index/check", {
  method: "POST",
  headers: {
    "X-API-Key": "sk-w2a-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    urls: ["https://www.onlinedown.net/article/10049071.htm"],
    engines: ["baidu"]
  })
});
const data = await resp.json();
if (resp.status !== 200) throw new Error("HTTP " + resp.status + ": " + data.error);
const baidu = data.results[0].engines.baidu;
console.log(baidu.error ? baidu.error.code : baidu.indexed);
先判断 HTTP 状态。收到 200 后逐条查看对应引擎结果。含 error 表示查询失败，indexed: false 表示本次查询完成但未命中。

GET/v1/index/check/jobs/{id}

批量任务进度 / 结果 / 取消(不计费)
收到 202 后保存 job_id。使用提交时的密钥请求 poll_url，任务进入 done 后用 results_url 获取 JSON，或用 csv_url 下载 CSV。链接已含 /web-tool。
所选引擎全部冷却时，任务进入 waiting，可按 wait_seconds 延长轮询间隔。cancelled 和 failed 也是终态，可读取已完成的结果。若提交时连接中断，先查最近任务，重复提交可能再次扣费。
参数类型必填说明
GET …/jobs—否最近任务列表,?limit=(默认 50,最大 500)
GET …/jobs/{id}——进度:status、progress、indexed/not_indexed/failed/retrying、eta_seconds、interval_ms
GET …/jobs/{id}/results—否结果行:?offset=&limit= 分页,?format=csv 直接下载表格(UTF-8 BOM)
DELETE …/jobs/{id}——取消排队中/运行中的任务;已结束返回 409 conflict
cURL
curl "https://radar.ydsdoa.cn/web-tool/v1/index/check/jobs/job_20261124T054613_379221272c" \
  -H "X-API-Key: sk-w2a-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

# 结果下载(CSV,Excel 可直接打开)
curl -OJ "https://radar.ydsdoa.cn/web-tool/v1/index/check/jobs/job_20261124T054613_379221272c/results?format=csv" \
  -H "X-API-Key: sk-w2a-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"

POST/web-tool/mcp

MCP Streamable HTTP(JSON-RPC 2.0)
MCP 端点供 AI Agent 直接调用平台能力。鉴权与计费规则与公网 API 相同(见「鉴权」)。
  • initialize — 握手,返回协议版本 2025-06-18 与 serverInfo(name 为 web2api)。
  • notifications/initialized — 握手确认,服务端返回 204。
  • tools/list — 列出可用工具。
  • tools/call — 调用工具。
  • ping — 连通性探测。
服务端通过 Mcp-Session-Id 响应头下发会话 ID,后续请求需原样带回。
参数类型必填说明
web_searchobjectquery 必填按关键词搜索,返回 rank、title、url、snippet。engine 可选 baidu|sogou|so360|bing,默认 baidu;limit 默认 10
check_indexedobjecturls 必填批量查询收录状态。≤20 条同步返回，>20 条转异步任务并返回 job_id。同步按成功单元计费，异步按提交单元计费。
get_index_jobobjectjob_id 必填查询异步收录任务进度(status/progress/eta_seconds);include_results=true 时附带结果行,不计费
cancel_index_jobobjectjob_id 必填取消排队中/运行中的收录任务,不计费
get_quotaobject—返回当前密钥的配额与用量
list_enginesobject—返回引擎清单与冷却、熔断状态
cURL · tools/call
curl -X POST "https://radar.ydsdoa.cn/web-tool/mcp" \
  -H "X-API-Key: sk-w2a-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"check_indexed","arguments":{"urls":["https://example.com/blog/post-1"],"engines":["baidu","bing"]}}}'

管理 API 与权限

登录后，程序可使用 Authorization: Bearer <JWT>，浏览器控制台使用会话 Cookie。角色权限依次为 viewer、operator、admin。角色不足返回 403 insufficient_role。
读取状态、统计、审计、用量及在线调试需要 viewer。密钥写操作、引擎冷却操作和黑名单管理需要 operator。用户管理、撤销指定会话、下载备份和日志清理需要 admin。
参数类型必填说明
POST /api/auth/login——管理员登录,返回 token、expires_in 与 user。同一用户名连续 5 次失败将锁定 15 分钟(换 IP 不重置),期间返回 429 too_many_attempts
POST /api/auth/passwordJSON—用 old_password 与 new_password 修改当前账号密码。新密码按服务配置校验。配置中的初始管理员改密会使全局旧 JWT 失效，其他账号改密撤销本人会话。
GET /api/me——当前管理员与调用概况
POST /api/keysJSON—创建密钥。name 必填，可传 daily_quota、expires_at 和 allowed_ips。完整密钥仅在创建或轮换时返回。
GET /api/keys——密钥列表(新→旧)
PATCH /api/keys/{id}JSON—更新名称、状态、日配额、过期时间或允许访问的 IP / CIDR。
DELETE /api/keys/{id}——删除密钥
GET /api/stats/overview——总览统计(今日 / 累计 / 24h 成功率)
GET /api/stats/timeseriesQuery—按日时间序列 ?days=1..90,默认 14
GET /api/usageQuery—使用日志 ?limit(≤200)&offset&key_id,分页返回总条数与 items 数组
GET /api/engines——每引擎状态:{ state: ok|cooldown|circuit_open, until, reason, consecutive_blocks, last_error_at }
POST /api/playground/checkJSON—面板在线调试。请求体为 urls(1–20 条)与可选 engines;响应结构与 /v1/index/check 完全一致;JWT 鉴权,不计费
POST /api/engines/{name}/cooldown/reset——强制恢复引擎:清除冷却与连续拦截计数
POST /api/engines/{name}/cooldown/forceJSON—强制冷却引擎。请求体为 minutes(1–720),供维护窗口使用
POST /api/keys/{id}/rotate——轮换密钥:保留名称 / 配额 / 计数,一次性返回新密钥;旧密钥即时失效
GET /api/sessions——管理员会话列表(IP / 最后活跃 / 当前会话标记)
DELETE /api/sessions/{id}——撤销指定会话;撤销当前会话等同退出登录
POST /api/auth/refresh——滑动续期当前会话
POST /api/auth/logout——退出登录:清除会话凭证
GET /api/auditQuery—安全审计轨迹 ?limit&offset,分页返回总条数与 items 数组(动作 / 对象 / 时间 / IP)
GET /api/usage/exportQuery—用量导出 ?format=csv|json&key_id&from&to
GET /api/reconcileQuery—记账对账 ?date=YYYY-MM-DD,返回扣费与流水差异数
GET /api/admin/backup——下载当前存储的 .db 或 .json 快照。
GET /api/runtime——查看内存、goroutine 数量、Go 版本及运行时长。
GET /api/users——查看用户、角色和状态。
POST /api/usersJSON—提交 username、password 和 role 创建用户。
PATCH /api/users/{id}JSON—更新角色或状态。
DELETE /api/users/{id}——删除用户。
POST /api/users/{id}/passwordJSON—提交 new_password 重置用户密码。
GET /api/blacklist——查看 IP 和 CIDR 规则。
POST /api/blacklistJSON—提交 value 创建规则，可设置备注和过期时间。
PATCH /api/blacklist/{id}JSON—修改备注或过期时间。
DELETE /api/blacklist/{id}——删除规则。
GET /api/logsQuery—使用 level、q、since、limit 和 offset 查询服务日志。
GET /api/logs/config——查看日志轮转和保留设置。
POST /api/logs/cleanup——按当前保留策略清理过期归档日志。

健康与引擎状态

字段说明
GET /health公开。整体健康或部分引擎可用时返回 200，全部不可用时返回 503。
GET /ready公开。返回 ready，服务停机排水时返回 503 和 draining。
GET /engines/status公开。返回冷却与熔断状态，冷却时可读取 until。该请求不会访问搜索引擎。
GET /stats、/stats/cache、/stats/proxy、/stats/cb配置模板默认需要 API Key，由 security.data_plane_auth 控制。
GET /metrics配置了指标专用 token 时使用 Bearer 鉴权，否则只允许回环来源。

限流与引擎冷却

  • 管理 API 限速:默认 60 次/分钟。超限返回 429,响应携带 Retry-After。
  • 登录防爆破:登录失败按用户名在不同来源间累计。达到实例配置的阈值后，登录返回 429 {"error":"too_many_attempts"} 与 Retry-After。
  • 引擎冷却由拦截（403）、429 或验证码触发。默认三档为 10、30、120 分钟，随仓库提供的配置将百度覆盖为 2、10、30 分钟。正常查完一批没有额外冷却，仍按引擎限流。
  • 同步收录请求开始时，若所选引擎全部已冷却，返回 503 engine_cooldown 和 Retry-After。若部分已冷却或批内触发冷却，被跳过的单元在 200 响应内给出 engine_cooldown 和剩余秒数。异步任务可以等待冷却结束。
  • 到期恢复:冷却到期后放行一个探测请求,成功即恢复,再次被拦截进下一档,其他失败(如超时)按当前档顺延重试。管理员可在「引擎状态」页强制恢复或强制冷却。

错误码

HTTP 级错误(整请求失败)
HTTPerror / code说明
400bad_request参数错误。reason:EMPTY_QUERY(URL 列表为空)、TOO_MANY_URLS(未开启 index_jobs 时 >20 条,或超过 index_jobs.max_urls)、INVALID_PARAM(参数非法)
401unauthorized密钥无效 / 已禁用,或管理员 JWT 缺失、过期
403blocked搜索引擎反爬拦截了请求(引擎级错误同样会以 code=blocked 出现在单元结果中)
403forbidden该请求被拒绝访问(如来源不在允许范围内)
404not_found接口或资源不存在(公网 API 挂在 /web-tool 前缀下,根路径 404)
405method_not_allowed该接口不支持此 HTTP 方法(如对 /v1/engines 使用 POST)
429quota_exceeded当日配额已用尽;带 Retry-After
429rate_limited请求过于频繁(公网或管理面限速);带 Retry-After
429too_many_attempts登录失败次数过多,已锁定;带 Retry-After
429captcha_detected引擎返回验证码(引擎级 429 不影响批量其它引擎)
503engine_cooldown同步查询开始时所选引擎全部冷却。按 Retry-After 或 retry_after_seconds 等待。
503job_queue_full / server_draining异步提交未入队也未扣费。按 Retry-After 等待后再提交。
503circuit_open / proxy_*熔断开启或代理类失败(auth / connect / timeout / unavailable)
504search_timeout / request_timeout / engine_queue_exceeded引擎搜索超时 / 整体请求超时 / 批量限流排队超出请求预算
501not_implemented该引擎未实现所请求的能力
502parser_failure / engine_internal / all_engines_failed解析失败 / 引擎内部错误 / 全部引擎失败
500server_error服务端内部错误
注:429 / 503 响应均携带 Retry-After(秒)。
引擎级错误(单元失败,HTTP 仍为 200) —— 出现在 results[].engines.<engine>.error.code:
HTTPerror / code说明
200blocked搜索引擎反爬拦截(403 / 429)
200captcha_detected引擎返回验证码
200engine_cooldown该引擎处于冷却窗口,快速失败
200circuit_open熔断器开启,未发起真实请求
200search_timeout引擎搜索超时
200engine_queue_exceeded该单元在引擎限流队列中等待超预算,未发起真实查询
200not_implemented引擎未实现该能力
200proxy_auth / proxy_connect / proxy_timeout / proxy_unavailable代理链路失败
200parser_failureSERP 解析失败
200engine_internal引擎内部错误
引擎级失败不改变整体响应:HTTP 仍为 200,其余引擎结果正常返回。
