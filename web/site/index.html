核心优势

为什么选 Web2API

批量查询四个引擎

最多 20 条 URL 同步返回。提交更多网址会返回任务 ID，可查询进度、读取结果或下载 CSV。

遇到风控时自动冷却

检测到拦截后暂缓向该引擎发起请求，到期后用一次请求探测是否恢复。冷却时长可按引擎配置。

Agent 直连

MCP streamable HTTP 与 OpenAPI 3.1 双入口,内置 llms.txt 能力清单;Claude Code、ChatGPT、Codex、VS Code Copilot 等客户端可接远程 MCP,Dify / n8n / LangChain 可直接导入 OpenAPI 规范。

单二进制自托管

纯 Go 单二进制 + bbolt 单文件存储,零外部数据库与服务依赖;四引擎搜索复用本机 Chrome,固定挂载 /web-tool 子路径部署。

一次判定的完整语义

服务在搜索结果中匹配目标网址。未命中可能与排名、跳转或结果窗口有关，建议用其他引擎交叉核对。

1

创建 API Key

控制台「API 密钥」页创建,完整 key 仅在创建响应中返回一次。

2

POST /web-tool/v1/index/check

提交 urls 与 engines:≤20 条同步返回,更多条自动入队并返回 job_id。

3

读取各引擎的 indexed 字段

match="exact" 表示命中目标网址，match="none" 表示此次查询未命中。

架构

一套服务，三种接入方式

查询 API

收录判定 + 四引擎原始搜索 + 配额查询,配额 / 限流 / 冷却内建。

POST /web-tool/v1/index/check批量收录判定(≤20 条同步;>20 条转异步任务)
GET /web-tool/v1/index/check/jobs/{id}异步任务进度 / 结果 / CSV 下载
GET /web-tool/v1/quota当前 key 的配额查询
GET /web-tool/{engine}/search四引擎原始搜索,实际形如 /web-tool/baidu/search、/web-tool/360/search
GET /web-tool/stats运行统计
鉴权:X-API-Key(search / stats 是否免鉴权随 security.data_plane_auth 开关)

Agent 接入

通过 MCP 或 OpenAPI 接入

MCP · STREAMABLE HTTP

使用远程 MCP

支持远程 Streamable HTTP。客户端可查询收录、发起搜索、查询配额，并跟踪或取消批量任务。连接时请携带 API 密钥。

claude mcp add --transport http web2api {{ORIGIN}}/web-tool/mcp --header "X-API-Key: sk-w2a-你的密钥"

其它客户端用等价配置(把 {{ORIGIN}} 换成你的服务地址):

{"mcpServers":{"web2api":{"type":"http","url":"{{ORIGIN}}/web-tool/mcp","headers":{"X-API-Key":"sk-w2a-…"}}}}
web_search check_indexed get_quota list_engines
在 OpenAPI 规范中查看 MCP 定义 ↗
OPENAPI · LLMS.TXT

导入 OpenAPI 规范

  • Dify「自定义工具 → 导入 OpenAPI」,鉴权选 API Key / Header X-API-Key
  • n8n「HTTP Request 节点 → Import cURL」粘贴请求,选 Header Auth 填 X-API-Key
  • LangChain「OpenAPI toolkit」加载 spec,或直接用 MCP 工具
  • ChatGPT / 自建 Agent按 llms.txt 能力清单调用 REST 或挂载 MCP
API 文档 GET /web-tool/openapi.yaml Agent 能力清单 llms.txt

鉴权:Header 型 API Key X-API-Key(计费;Authorization: Bearer <密钥本体> 等效)。MCP 端点另接受 Authorization: Bearer <管理员JWT>(不计费,仅限管理员)。无鉴权请求一律 401,不暴露裸端点。spec 地址 /web-tool/openapi.yaml(浏览器打开即网页视图,程序化导入自动取得原始 YAML)。请先在控制台创建密钥。

分档冷却与恢复探测

引擎被拦截时进入冷却，连续被拦截时逐档延长。随附配置中，百度使用 2 / 10 / 30 分钟，其他引擎使用 10 / 30 / 120 分钟。

冷却期间暂停向该引擎发起搜索请求。到期后先探测，成功后恢复。重试规则详见 API 文档。

快速开始

三步完成首次收录查询

1 获取 API 密钥 打开控制台 
登录控制台 → 「API 密钥」页 → 创建密钥
密钥格式 sk-w2a-…,仅在创建时展示完整密钥，请及时保存
2 发起收录判定 
curl -X POST {{ORIGIN}}/web-tool/v1/index/check \
  -H "X-API-Key: sk-w2a-…" -H "Content-Type: application/json" \
  -d '{"urls":["https://example.com/post-1"],"engines":["baidu","bing"]}'
3 读取判定结果 
{
  "results": [{
    "url": "https://example.com/post-1",
    "engines": {
      "baidu": { "indexed": true,  "match": "exact", "matched_result_url": "https://example.com/post-1", "total_results": 9, "took_ms": 812 },
      "bing":  { "indexed": false, "match": "none",  "matched_result_url": "", "total_results": 10, "took_ms": 940 }
    }
  }],
  "meta": { "request_id": "01a1…", "took_ms": 2541, "units": 2 }
}

indexed 表示本次搜索是否命中，match 表示匹配方式。meta.units 是请求单元总数；同步查询按成功单元计费，单个引擎失败会在对应结果中返回 error。

更多端点:GET 单 URL 判定、GET /web-tool/v1/quota 配额查询、GET /{engine}/search 四引擎搜索 —— 全部见 API 文档(OpenAPI 3.1)。

AI Agent 接入:MCP Server 一条命令即用,见上方 Agent 接入区。
