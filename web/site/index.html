核心优势

为什么选 Web2API

一次调用,判定四引擎

POST /web-tool/v1/index/check 支持整表提交:≤20 条同步返回,更多条自动转服务端任务队列(202 + job_id,进度/结果/CSV 走 /v1/index/check/jobs/{id}),按引擎实测节奏排队跑完;逐引擎返回 indexed 与匹配详情;1 条 URL × 1 个引擎 = 1 次,计费口径清晰。

风控自动冷却,无需人工干预

连续拦截按 10 / 30 / 120 分钟三档自动冷却,240 分钟无拦截计数归零;冷却期零真实请求,到期探测恢复。

Agent 直连

MCP streamable HTTP 与 OpenAPI 3.1 双入口,内置 llms.txt 能力清单;Claude Code、ChatGPT、Codex、VS Code Copilot 等客户端可接远程 MCP,Dify / n8n / LangChain 可直接导入 OpenAPI 规范。

单二进制,可自托管

纯 Go 单二进制 + bbolt 单文件存储,零外部数据库与服务依赖;四引擎搜索复用本机 Chrome,固定挂载 /web-tool 子路径部署。

一次判定的完整语义

判定语义:以 URL 为查询词检索引擎前 10 条结果,跳转链接还原后归一化匹配;目标 URL 不在这 10 条结果中(如未上榜的深链接)会漏报为未收录,建议多引擎交叉验证。

1

创建 API Key

控制台「API 密钥」页创建,完整 key 仅在创建响应中返回一次。

2

POST /web-tool/v1/index/check

提交 urls 与 engines:≤20 条同步返回,更多条自动入队并返回 job_id。

3

读取 results[].engines[].indexed

match="exact" 即已收录;match="none" 仅表示前 10 条结果中未命中,深链接建议多引擎交叉验证。

数据平面

Agent 接入

为 Agent 而生的两条入口

MCP · STREAMABLE HTTP

一个 MCP Server,主流 Agent 通用

标准 MCP streamable HTTP(JSON-RPC 2.0),内置 web_search、check_indexed、get_index_job、cancel_index_job、get_quota、list_engines 六个工具(批量收录可一次提交整表再轮询进度)。Claude Code、Claude Desktop、ChatGPT、Codex、VS Code Copilot 等已支持远程 MCP 的客户端可直接接入;Cursor、Windsurf、Cline、Gemini CLI 等以各自文档的远程传输支持为准。必须携带 API Key,无鉴权请求一律 401。

claude mcp add --transport http web2api {{ORIGIN}}/web-tool/mcp --header "X-API-Key: sk-w2a-你的密钥"

其它客户端用等价配置(把 {{ORIGIN}} 换成你的服务地址):

{"mcpServers":{"web2api":{"type":"http","url":"{{ORIGIN}}/web-tool/mcp","headers":{"X-API-Key":"sk-w2a-…"}}}}

鉴权:Header 型 API Key X-API-Key(计费;Authorization: Bearer <密钥本体> 等效)。MCP 端点另接受 Authorization: Bearer <管理员JWT>(不计费,仅限管理员)。无鉴权请求一律 401,不暴露裸端点。spec 地址 /web-tool/openapi.yaml(浏览器打开即网页视图,程序化导入自动取得原始 YAML)。请先在控制台创建密钥。

三档冷却,自动恢复

连续拦截触发冷却:第 1 次 10 分钟、第 2 次 30 分钟、第 3 次及以上 120 分钟;连续 240 分钟无拦截自动归零。到期后放行一个探测请求:成功即恢复,再次被拦截进下一档,其他失败(如超时)按当前档顺延重试。

冷却期内该引擎零接触:相关请求快速失败且不消耗配额,到期自动恢复,全程无需人工干预。客户端接入细节见 API 文档。

快速开始

三步,跑通你的第一次收录判定

1 获取 API 密钥 打开控制台 
登录控制台 → 「API 密钥」页 → 创建密钥
密钥格式 sk-w2a-…,仅在创建时完整展示一次,请立即保存
2 发起收录判定 
curl -X POST {{ORIGIN}}/web-tool/v1/index/check \
  -H "X-API-Key: sk-w2a-…" -H "Content-Type: application/json" \
  -d '{"urls":["https://example.com/post-1"],"engines":["baidu","bing"]}'
3 读取判定结果 
{
  "results": [{
    "url": "https://example.com/post-1",
    "engines": {
      "baidu": { "indexed": true,  "match": "exact", "matched_result_url": "https://example.com/post-1", "total_results": 9, "took_ms": 812 },
      "bing":  { "indexed": false, "match": "none",  "matched_result_url": "", "total_results": 10, "took_ms": 940 }
    }
  }],
  "meta": { "request_id": "01a1…", "took_ms": 2541, "units": 2 }
}

结果字段:indexed 是否收录 · match 匹配精度(exact / none) · meta.units 本次计费次数,字段 units(1 条 URL × 1 个引擎 = 1 次;按成功单元计费,失败单元不计费)。引擎级失败不拖垮整体,对应项返回 error。

更多端点:GET 单 URL 判定、GET /web-tool/v1/quota 配额查询、GET /{engine}/search 四引擎搜索 —— 全部见 API 文档(OpenAPI 3.1)。
