核心优势

为什么选 Web2API

一次调用,判定四引擎

POST /v1/index/check 一次提交最多 20 条 URL,逐引擎返回 indexed 与匹配详情;1 URL × 1 引擎 = 1 unit,计费口径清晰。

引擎风控,冷却自愈

连续拦截按 10 / 30 / 120 分钟三档自动冷却,240 分钟无拦截计数归零;冷却期零真实请求,到期探测恢复。

Agent 一等公民

MCP streamable HTTP 与 OpenAPI 3.1 双入口,内置 llms.txt 能力清单;Claude / Dify / Coze / n8n / LangChain 直接导入。

单二进制,可自托管

纯 Go 单二进制 + bbolt 单文件存储,零外部依赖;固定挂载 /web-tool 子路径,数据始终留在你的机器上。

引擎风控

冷却不是故障,是自愈

三档冷却,自动恢复

连续拦截触发冷却:第 1 次 10 分钟、第 2 次 30 分钟、第 3 次及以上 120 分钟;连续 240 分钟无拦截自动归零。到期后放行一个探测请求,成功恢复、失败进下一档。

冷却期内该引擎零接触:search / check 快速失败(HTTP 503 engine_cooldown 信封 + Retry-After),不发真实请求、不消耗配额;批量判定自动绕行,响应 meta.engines_cooldown 会列出冷却中的引擎,客户端据此跳过,并在 Retry-After 后重试。

baidu百度 正常
sogou搜狗 冷却 剩余 09:42
so360360 搜索 正常
bing必应 熔断

示意状态,用于说明「正常 / 冷却 / 熔断」三种语义;实时倒计时与运维操作见控制台「引擎状态」页(10 秒自动刷新)。

快速开始

Docker 一条命令,自托管上线

1 启动服务并检查健康 
docker compose -f deploy/docker-compose.yml up -d --build
curl http://127.0.0.1:7000/web-tool/health
2 发起首个收录判定 
curl -X POST http://127.0.0.1:7000/web-tool/v1/index/check \
  -H "X-API-Key: sk-w2a-…" -H "Content-Type: application/json" \
  -d '{"urls":["https://example.com/post-1"],"engines":["baidu","bing"]}'

部署完成后,浏览器打开 http://127.0.0.1:7000/web-tool/ 进入官网(即本页);需要本机装有 Chrome / Chromium / Edge,浏览器模式默认开启。

管理面板位于 /web-tool/console/,默认管理员 admin / admin123 —— 部署后立即在面板「系统设置」页修改密码。
