# web2api 安全与计费复核

本轮从本地工作树重新核对了基线 `8d85b10` 的四项发现。重点检查启动保护、请求代理、MCP 配额和管理员登录锁定。前三项在代码层处理，账号锁定的可用性风险由 Nginx 管理入口白名单缓解。本轮验证覆盖本地代码和部署示例。

## 发现与处理

| 编号 | 发现 | 处理与证据 |
| --- | --- | --- |
| F1 | 高危，有部署前提。应用监听回环地址时，公网反代可使出厂凭据仍然有效。 | 对外监听或启用受信反代时，保留出厂密码会拒绝启动。直接回环开发仍可启动。部署模板要求提供管理员密码并限制管理路由来源。 [启动检查](../../cmd/serve.go#L658) · [回归测试](../../cmd/serve_test.go#L15) · [反代示例](../DEPLOYMENT.md#5-反向代理tls-终结) |
| F2 | 中危，默认关闭。启用自带代理后，调用方提供的地址可以使服务向非公网地址建立连接。 | 搜索接口和指纹检查只接受公网 IP 字面地址作为调用方指定的代理主机，避免客户端重新解析代理名。通过管理员配置的代理可继续使用域名。 [地址检查](../../core/proxy.go#L252) · [回归测试](../../core/proxy_test.go#L62) |
| F3 | 中等计费影响。MCP 参数错误使用 HTTP 200，旧逻辑可能按预估值扣除配额。 | JSON-RPC 错误及没有引擎明细的工具错误不扣费。有明细时按成功单元计费。未知引擎和显式空列表也不再预留配额。 [计费逻辑](../../platform/security.go#L455) · [回归测试](../../platform/security_test.go#L492) |
| F4 | 低危，有部署前提。公开登录路由允许外部请求触发管理员账号锁定。 | 保留按用户名跨 IP 锁定。Nginx 示例默认只向回环来源开放控制台与管理 API，远程管理使用实际管理网段。 [锁定测试](../../platform/security_test.go#L61) · [反代示例](../DEPLOYMENT.md#5-反向代理tls-终结) |

## 验证与部署状态

- Go 1.26.11 下 `go test ./...` 和 `go vet ./...` 通过。
- 文档中的反代配置在 Nginx 1.31.8 容器中使用临时证书通过 `nginx -t`，原有 HTTP/2 写法产生弃用提示。
- 线上配置未变更，未探测线上服务。现有部署的边缘限制在应用配置模板后生效。回环反代需要启用受信代理设置，应用才能在启动时识别这一部署模式。
